# Vivaz Garden

## Sobre o Projeto

O Vivaz Garden é uma landing page desenvolvida para apresentar um espaço de eventos voltado para a realização de casamentos, aniversários, formaturas e eventos corporativos.

O site foi projetado com foco na experiência do usuário, oferecendo uma interface moderna e intuitiva para que visitantes possam conhecer o espaço, visualizar fotos do ambiente, explorar os tipos de eventos realizados e entrar em contato de forma rápida através das redes sociais e WhatsApp.

## Funcionalidades

* Página inicial com apresentação do espaço
* Galeria de fotos do ambiente
* Seção de serviços e tipos de eventos realizados
* Botão de localização
* Integração com Instagram
* Integração com WhatsApp para contato direto
* Navegação simples e responsiva

## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* Git
* GitHub

## Tipos de Eventos

O Vivaz Garden oferece estrutura para diversos tipos de eventos:

* Casamentos
* Aniversários
* Eventos Corporativos
* Formaturas

## Objetivo do Projeto

Este projeto foi desenvolvido com o objetivo de praticar conceitos de desenvolvimento web, incluindo estruturação de páginas, estilização com CSS, responsividade, organização de componentes e experiência do usuário.

## Como Executar

1. Clone este repositório:

```bash
git clone https://github.com/seu-usuario/vivaz-garden.git
```

2. Abra o arquivo `index.html` em seu navegador.

## Aprendizados

Durante o desenvolvimento deste projeto foram aplicados conceitos como:

* Estruturação semântica de páginas web
* Responsividade
* Navegação por seções
* Organização de layout
* Manipulação de elementos visuais
* Boas práticas de desenvolvimento front-end
